## Welcome to Hoyotod 👋

Hoyotod is an organization focused on creating tools and utilities for game automation, reward management, and promotional code distribution. We build solutions to streamline repetitive tasks and enhance gaming experiences.

## 📦 Projects

### [code](https://github.com/Hoyotod/code)
Latest promotional codes aggregator. A Python-based utility for managing and distributing promotional codes.

### [daily](https://github.com/Hoyotod/daily)
Claim daily reward automation. Streamline your daily reward claiming process with automated scripts.

### [redeem](https://github.com/Hoyotod/redeem)
Auto redeem code utility. Automatically redeem promotional codes without manual effort.

### [hoyo](https://github.com/Hoyotod/hoyo)
Web application for managing Hoyoverse game utilities. Built with TypeScript and deployed at [hoyo-tau.vercel.app](https://hoyo-tau.vercel.app).
